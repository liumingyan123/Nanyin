# E4 采样超参（temperature / top-p）网格搜索汇总报告

- 分支：`experiment/E4_sampling_search`（基线 `experiment/E3_loss_ablation` @ `1df1c83`）
- 日期：2026-09-23
- 产物/配置源：`configs/e4_sampling_search.yaml`

## 0. 前置背景与硬性约束（贯彻本报告全部结论）

1. **E4 不做任何训练**。权重全部固定取自 **E3-L3 三个随机种子（2026/2027/2028）的 best-val 早停 checkpoint**
   （早停监控 = 验证集三路加权 CE；best epoch 8 / 9 / 7，val CE 6.8635 / 6.8657 / 6.8418）。
   未加载任何非 best-val 的过拟合权重，未做微调/权重修改。
2. **只改变推理采样超参**（temperature、top-p）。模型结构、词表、窗口切分、数据划分、掩码规则全部继承 E2/E3。
3. **评估全部使用模型原生输出**：未开启任何 MIDI 规则后处理、未做时值钳位修正
   （`postprocess.enable_clamp / enable_deduplicate / enable_legato_fix / enable_rescale` 全 false，仅预留开关）。
4. **重要认知：采样策略无法修复训练阶段的底层缺陷。** E2/E3 已记录 —— duration / time-shift 词表长尾、
   细档 token 识别准确率极低（E3-L3 duration head 验证集 token acc 仅 **6.53%**）。
   调 temperature / top-p **只能改变生成多样性与非法事件比例**，不能提升细档判别能力。
   本报告所有结论都在这个前提下解读。

## 2. 单元测试（`tests/test_sampling_consistency.py`）

**23/23 PASS**（设备 cuda，明细 `results/e4/e4_sampling_consistency_test.json`）。关键点：

- **T1 可复现**：同权重 + 同 (T=0.8, p=0.9) + 同 rng_seed 跑两次 → 三路 256 事件序列**逐位相同**。
- **T2 / T3**：换 rng_seed、换 T（0.8→1.2）、换 top-p（0.9→0.7）序列均改变 → 可复现不是"退化成贪心"，采样参数确实生效。
- **T4 prompt 对齐**：生成序列前 16 事件 == 窗口 GT 前 16 事件（pitch/duration/shift 三路逐位）；总长 = 256。
- **T5 窗口口径**：10 个验证窗口，窗口长度 256，编号/起始事件号与 `CompoundEventWindowDataset` records 一致。
- **T7 46 维特征**：维数 46、有限、确定性。

> 单元测试全部 PASS 之后才启动上述 480 条批量生成（符合 E4 开发流程第 1→2 步）。

## 4. 三个维度的观察

### 4.1 composite 质量：随"采样熵"单调上升，但升幅几乎全部来自 tempo_accuracy

- 最优 **67.39（T=1.2 / p=0.95）**，最差 58.05（T=0.8 / p=0.80），极差 9.34 分；GT 天花板 82.76 —— **最好的采样配置仍比 GT 低 15.4 分**。
- 沿单调方向（T↑ 且 p↑）：`tempo_accuracy` 从 52.6~56.3 涨到 **79.98~85.18**（+28~32 分），是 composite 提升的**主驱动**；
  `rhythm_consistency`（约 57~61）、`pitch_stability`（91.1~94.0，略降）、`mode_matching`（84~90，无趋势）基本不动。
- 同时 composite 的**组内标准差随熵上升而变小**：7.07（0.6/0.7）→ 2.78（1.2/0.95），说明高熵配置的输出更稳定、更不依赖具体窗口。

### 4.2 非法事件率：**全部 16 组均为 0.0000**（480 条序列，合计 0 个非法 token）

- 统计口径：续写 240 事件中 pitch ≥ 128（特殊 token）、duration ≥ 402 或 =0、shift ≥ 1002 或 =0；
  窗口最后一位 shift 是伪标签不计入。480 条 × 240 事件 = 115,200 个 token，**零非法**。
- 解释：在本网格内（p ≤ 0.95），top-p 截断把长尾（含 PAD / 溢出档 / 特殊 token）一并裁掉，模型在续写位置也几乎不给特殊 token 概率。
- ⚠ **不能外推**：本结论只在 T ≤ 1.2、p ≤ 0.95 范围内成立。更大的 T（如 1.5+）或更松的 p（如 0.99/1.0）**未测试**，不能断言"不会产生非法时值/shift"。
- 因此本轮**没有观察到"某些参数产生大量非法时值/shift"**的现象；真正的风险不在非法 token，而在第 4.3 节的"循环退化"。

### 4.3 生成多样性：低熵 = 循环退化，高熵 = 局部旋律结构崩塌

- **4-gram 重复率**随采样熵单调下降：0.865（0.6/0.7）→ 0.063（1.2/0.95）。
  **退化区（重复率 > 0.5，共 11/16 组）**：几乎所有 T ≤ 0.8 且 p ≤ 0.8 的组合，
  以及 0.6/0.9、0.6/0.95、0.8/0.9、1.0/0.7、1.0/0.8、1.2/0.7 ——
  这些配置生成的是"不断复述同一串短循环"，与 E2/E3 记录的"模型倾向于复制最近 token"完全一致。
- **`struct`（transition_smoothness + melody_coherence 的平均）反向崩塌**：45.9（0.8/0.7）→ 1.8（1.2/0.95）。
  关键在于 **这两个指标并不包含在 composite 公式内部**（composite 只用 pitch_accuracy/pitch_stability、
  rhythm/tempo、ornament 类、mode、style），所以"composite 最高的配置"恰恰是局部旋律结构最碎的：
  `transition_smoothness` 58.3 → 3.5、`melody_coherence` 24.7 → 0.0。
- **两种多样性口径给出相反排序**（这是本轮最需要注意的方法学陷阱）：
  - `interDiv`（与其它配置的距离）：低熵配置反而最高（1.18），因为"每个退化循环都各不相同"；
  - `seedDiv`（换训练种子的距离）：低熵配置最高（1.38），因为三套权重各循各自的循环；高熵时反而收敛（0.34）。
  → 单纯"多样性越大越好"会把最优解误判成 0.6/0.7 这种退化配置。真正有信息量的是 `gtDist`
  （到 GT 46 维特征的距离），它随熵单调下降 1.62 → 0.40，即高熵输出在符号分布上更接近 GT。

## 5. 综合权衡与最优配置选择

不同准则会给出不同 winner（等权 min-max 归一化后取和）：

| 准则 | 最优 | top-3 |
|---|---|---|
| A 只看 composite | T=1.2, p=0.95 | 1.2/0.95, 1.2/0.9, 1.0/0.95 |
| B composite + 反重复率 | T=1.2, p=0.95 | 1.2/0.95, 1.2/0.9, 1.0/0.95 |
| C composite + 局部结构 | T=0.6, p=0.80 | 0.6/0.8, 0.6/0.7, 0.8/0.7 |
| D composite + 反重复 + 结构 + 跨种子多样性 | T=0.6, p=0.80 | 0.6/0.8, 0.6/0.7, 1.0/0.95 |
| E 五项全含（含两种多样性） | T=0.6, p=0.70 | 0.6/0.7, 0.6/0.8, 0.8/0.7 |

→ **准则 C/D/E 的最优都是重复率 0.79~0.87 的退化配置**，不能采纳（它们高分只是因为"退化循环"同时抬高了
melody_coherence / 多样性指标）。必须在"剔除退化"和"结构不崩塌"之后再看 composite。

**推荐（综合最优）：`temperature = 1.0, top-p = 0.95`**

选择理由（不能只看 composite 单项）：

1. **质量处于第一梯队且与最高值不可区分**：composite 66.81 ± 2.62（rank 3），与最高的 67.39 相差 **0.58**，
   小于两者自身 std（2.62 / 2.78）与跨种子 std（0.78 / 0.41）→ 统计上并列第一梯队。
2. **跨随机种子最稳健**：三个训练种子得分 67.81 / 66.71 / 65.91，跨种子 std **0.78**（全网格第 2 稳，仅次于 1.2/0.95 的 0.41）；
   相比之下低熵配置可达 6.45~7.07。→ 换一份权重结论不会翻转。
3. **非退化**：4-gram 重复率 0.165，远低于退化阈值 0.5。
4. **在 top-3 里局部结构保留最好**：struct 5.90（1.2/0.95 只有 1.77、1.2/0.9 为 3.55）；
   melody_coherence 与 transition_smoothness 虽仍偏低，但没有跌到"完全无结构"。
5. **方法论上最中性**：T=1.0 **不改变模型学到的分布**（不加温、不锐化），top-p=0.95 只截断长尾。
   在 composite 已统计并列的前提下，优先选不对分布做额外形变的一档，可辩护性强于 T=1.2。
6. 符号分布贴近 GT：gtDist 0.512，接近最优的 0.395。

备选：

- 若下游只追求**分布贴合/节奏自然**（不关心局部连贯）：`T=1.2, p=0.90`（composite 67.21，重复率 0.150，std 2.66）。
- 若下游需要**局部旋律连贯**（如要人工试听续写片段）：`T=0.8, p=0.95`（struct 13.40，为高 p 区最高；composite 63.47），
  代价是 composite 低约 3.3 分、退化倾向回升（重复率 0.465）。

**明确记录的风险参数（不建议使用）**：

- 易产生**大量重复（退化）**的参数：T ≤ 0.8 且 p ≤ 0.8 的全部组合，以及 0.6/0.9、0.6/0.95、0.8/0.9、1.0/0.7、1.0/0.8、1.2/0.7
  （4-gram 重复率 > 0.5，最高 0.865）。
- **多样性过低**的参数：T=1.2 / p=0.95 与 1.2 / p=0.90（seedDiv 0.336 / 0.388，为全网格最低两档），
  含义是"换训练种子也换不出太不一样的结果"，若下游需要多样候选，这两档偏保守。
- 本网格内**所有**配置的非法率均为 0；**未发现**"某参数导致大量非法时值/shift"的证据（但范围外未验证）。

## 6. 局限（如实记录）

1. **采样救不了训练缺陷**：duration / time-shift 细档 token 识别准确率仍极低（E3-L3 duration token acc 6.53%），
   “时值量化 402 档、shift 1002 档的长尾分布学习不足”这一底层问题在本阶段无法通过调参改变。
2. **验证规模小**：仅 2 首曲 × 10 个非重叠窗口 × 3 个模型种子；每配置 30 样本，标差 2.6~7.1，
   因此 composite 前 3 名的差异（≤0.58 分）**不可区分**，本报告的最优选择带主观权衡成分，已写明理由。
3. **composite 公式本身有盲区**：transition_smoothness / melody_coherence 未计入 composite，
   导致"composite 越高"与"局部旋律越连贯"在本实验中负相关 —— 这正是不能做"越高越好"简单结论的原因。
4. **网格外未探索**：T > 1.2、p > 0.95、top-k ≠ 0、以及 per-head 分路超参均未测试。
5. **未做人工试听核验**：结论全部基于 Tier-1 符号级指标；audio 级（Tier-2）评估不在本阶段范围。
