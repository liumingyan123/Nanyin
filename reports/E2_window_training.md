## 1. 目标与范围

在 E1 已完成并通过自测的复合事件编解码基础上，做**滑窗样本构建 + BoYaTCN 窗口训练**：

- 样本粒度：256 事件/窗口（不再是整曲）；
- 损失：`total = 1.0 * pitch_CE + 0.7 * duration_CE + 0.7 * shift_CE`；
- **本阶段不做 L0-L5 损失消融**（无音级 / 调式 / IOI 额外损失），消融留给 E3；
- 不生成 MIDI、不做评估（E3 及以后）。

## 2. 窗口切分设计与单元自测结果

| 项 | 规则 |
|---|---|
| 窗口长度 | 256 **事件**（复合序列长度，非时间长度）|
| 训练集步长 | 128（50% 重叠滑动）|
| 验证/测试集步长 | 256（非重叠取样）|
| 不足窗口长度 | 尾段**直接丢弃**，不做 padding |
| 曲目 ID 隔离 | 窗口在单曲内部切；训练 9 首 / 验证 2 首，ID 无交集 |
| BOS / EOS | 输入 = `[BOS] + 256 事件`，目标 = `256 事件 + [EOS]`，样本长度 257 |
| attention_mask | 长度 257，**恒为全 1**（等长窗口无 padding；变长 batch 时才出现 0）|
| time-shift 掩码 | 目标序列**最后事件位 + EOS 位**置 `IGNORE_INDEX=-100`，不进损失与反向传播 |

`tests/test_window_slice.py` 实测 **22/22 项 PASS**（明细 `results/e2_window_slice_test.json`），关键判定：

- 窗口数量公式：n=255→0、256→1、257→1、384→2、600→3（步长128）；600→2、1024→4（步长256）；
- 伪标签屏蔽的三层验证：① 位置（末两位 = -100，其余保留真值）；② 损失等价
  `CE(ignore_index) == 手工只对有效位求 CE`（差 0.00e+00），且**不屏蔽时损失不同**（7.4636 vs 7.4647，证明掩码真实生效）；
  ③ 梯度：被屏蔽位置 logits 梯度**严格为 0**（0.0e+00），有效位 1.998e+00 → 伪标签确实不回传。
- 窗口事件 = 整曲编码对应切片（shift 末位置 0 除外），解码 onset 单调不回退。

## 7. 诚实结论与已知问题（不隐藏失败）

1. **严重过拟合**：训练 loss 从 9.34 单调降到 1.84，验证 loss 却在第 5~7 轮见底（6.88）后一路升到 10.19。
   248 个窗口 / 9 首曲子喂 3.44M 参数模型，第 7 轮之后基本是在背训练集；best-val 落在 epoch 7。
2. **duration 头几乎没学到东西**：验证 token 准确率 epoch 1 是 7.12%，best 轮 7.00%，末轮 5.84%——
   全程在"多数类猜测"水平附近（Top1 类别占比仅约 10.8%，即多数类基线 ≈10.8%，模型甚至低于该基线）。
   时值档位 404 类、分布集中但类别细，需要更长时间/更大权重/或改分箱（见 6）。
3. **shift 验证准确率随训练下降**（24.98% → best 轮 23.22% → 末轮 11.14%），与过拟合一致。
4. **验证集过小**：仅 2 首曲子、10 个非重叠窗口，val loss 抖动大、统计意义弱；
   早停判定"连续 20 轮未下降"在小验证集上容易过敏感。
5. **伪标签掩码的代价（如实记录）**：对**非末尾窗口**，最后一个事件到下一个音符的真实 shift 在整曲中
   是可知的，本实现按 E1 约定一律视为未定义并屏蔽 → 每个窗口舍弃 1 个真实可得的 shift 监督（248 个/轮）。
   选择一致处理是为了让窗口尾部语义与"第 256 个事件后接 EOS"的生成行为一致；若 E3 想回收这批监督，
   需额外区分"整曲末尾窗口"与"中段窗口"。
6. **GT 噪声（已写入 `dataset_nanyin.py` 注释）**：GT 来自 BasicPitch 自动转录，存在同音重叠音符；
   编码阶段保留转录原时值，但写回 MIDI 时为避免 (channel,pitch) 配对歧义丢音，会把前一音截断到后一音起点，
   **引入局部时值噪声**（E1 实测每首 20~311 处）。模型学到的时值分布会继承该偏差，论文须记录。
7. **截断噪声**：6 首训练曲被 `max_notes=4096` 截断（合计丢弃 7282 个音符），后半段未参与训练。
8. 本次未做：L0-L5 损失消融（E3）、生成与评估（E3+）、MusicMamba 对照训练。
